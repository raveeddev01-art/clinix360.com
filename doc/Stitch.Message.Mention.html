    Link to this function user_mention_keywords(users, author)

    Initially, use user nicknames. Expand later to add other keywords user might wish to be notified of, depending on user group preferences. Note, in some case, user might want to disable certain notifications (globally or only for a specific group). Excludes authors.

    Example of keywords:

    • @here, @all, @everyone
    • @group,
    • username
    • user’s first/last/full name, depending on notificaiton preferences

    • user’s custom keywords for this group

      Stitch.Mention.user_mention_keywords([ %{id: 1, username: “bob”}, %{id: 2, username: “alice”} ], %{username: “bob”})

      %{ “@bob” => [], “@alice” => [2], “@all” => [1, 2] }
