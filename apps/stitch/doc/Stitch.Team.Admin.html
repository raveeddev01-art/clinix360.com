    Deletes the team from the database including all associated records. This is DANGEROUS and not reversible

    export_history(team_id)

    Generates a .zip file containing all of the data exported for the team. It uploads the contents to an S3 bucket which can only be accessed using a special associated token. Returns true if the export went correctly
